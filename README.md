# Market Current

A small Next.js site for checking trending stocks each day and keeping a local watchlist with notes.

## Run locally

```bash
npm install
npm run dev
```
  

## What it includes

- A daily market board powered by a server-side Yahoo Finance fetch.
- A daily news section that pulls the latest headlines for the most active trending stocks.
- A curated fallback board if the live feed is unavailable.
- A browser-saved watchlist so tracked stocks, manual symbol adds, and notes persist across visits.
